Cburnett chess piece artwork

The SVG files in the cburnett directory are the Cburnett chess-piece set by
Colin M. L. Burnett, bundled unmodified from the Lichess lila repository:

https://github.com/lichess-org/lila/tree/master/public/piece/cburnett

License, version 2 or any later version (GPLv2+). The complete GPLv2 text is
included in GPL-2.0.txt.

own source code remains released under the Unlicense.
